# Sistema de Notas do Aluno
### Descrição
um código simples de cálculo de duas notas com uma média 2.

## Requisitos

Python 3.x

## Como executar

tenha o codigo no VScode(Visual Studio Code) e a extensão do Python mais recente e execute o codigo.

Digite as duas notas quando solicitado.
